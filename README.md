# DinersCrush 🍽️⚡

Food delivery platform that pays drivers fair. Built for drivers, by a driver.

## Features

- Authentication (Restaurants, Drivers, Admin)
- Restaurant Dashboard – manage orders and menu
- Driver Dashboard – online/offline, earnings
- Customer ordering interface
- 15% commission vs 30% on other platforms
- Drivers get $6-8 minimum per delivery + tips

## Tech Stack

- React + TypeScript
- Tailwind CSS
- Firebase
- Vite
- Netlify
